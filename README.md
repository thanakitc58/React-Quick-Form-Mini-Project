# React Quick Form Mini Project

แอปสำรวจความชอบภาพยนตร์ที่สร้างด้วย React และ Tailwind CSS

## 🚀 ภาษาที่ใช้

- ⚛️ **React** - UI Library
- ⚡ **Vite** - Build Tool
- 🎨 **Tailwind CSS** - Styling Framework
- 📜 **JavaScript** - Programming Language

## 📋 Features

- ✍️ กรอกชื่อและอีเมล (พร้อม validation)
- 🎬 เลือกภาพยนตร์ที่ชอบจากรายการ
- 💬 แสดงความคิดเห็น (optional)
- ✔️ Form validation และแสดงข้อความแจ้งเตือน
- 📊 หน้าสรุปข้อมูลที่กรอก
- 🔄 ปุ่มรีเซ็ตฟอร์ม

## 🛠️ การติดตั้งและรัน

### ติดตั้ง Dependencies
```bash
npm install
```

### รัน Development Server
```bash
npm run dev
```

## 📁 โครงสร้างโปรเจกต์

```
src/
├── components/     # React Components
├── data/           # เก็บข้อมูลหนัง
├── App.jsx         # Main Component
└── main.jsx        # Entry Point
```

## 📝 Code Quality Principles

- **DRY** - ไม่เขียนโค้ดซ้ำ
- **High Cohesion** - จัดโครงสร้างไฟล์ตามหน้าที่
- **Loose Coupling** - คอมโพเนนต์สื่อสารผ่าน props
- **Single Responsibility** - แต่ละฟังก์ชันมีหน้าที่เดียว
